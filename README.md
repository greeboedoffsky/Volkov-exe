# Volkov-exe
Тут курс Волкова по моделированию
он содержит три этапа:
***
№1 вычисление числа \pi
---
через интегрирование четверть сферы по Монте-Карло вычисляем значение числа \pi, генератор псевдослучайных чисел на C выдал точность в три знака после запятой))))))

№2 модель идеального газа
---
используется генератор случайных чисел с нулл на время, делается какой-то шаг, потом принимается и пишется в массив с учетом периодических граничных условий

№3 модель твёрдых сфер
---
Реализуем метод Метрополиса. Тут модель в которой молекулы не могут ппроникать сквозь друг друга, минимальное расстояние по методу ближайшего образа

№4 Леннард-Джонсовский потенциал
---
Реализуем метод Метрополиса. Тут мы убрали отбор по минимальному радиусу и добавили потенциал, после каждой случайной сдвижки мы обсчитываем разницу потенциальных энергий, кинетическую энергия не учитываем
